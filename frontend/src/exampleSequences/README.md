# Example Sequences

This folder contains pre-packaged example diagrams in `.nmrd` format for the application.

## Adding Custom Example Sequences
To add a new example diagram to the application:
1. Export or save a diagram as an `.nmrd` file.
2. Drag and drop the `.nmrd` file directly into this folder.
3. The file will automatically be detected and listed under **Example Sequences** in the **Load Diagram** dialog!
