# Label

The `Label` an `Annotation` object is a `LaTex`-`Line` pair that is positioned inside an aligner so they can be nicey arranged relative to eachother. This element is useful for creating labeled spans of pulses to annotate duration related statistcs. 

### Text Position

The line and text objects can be positioned relative to eachother by changing the `Text Position` attribute found in the `Form`. This changes whether the `LaTeX` object is located above, below or inline with the `Line` object.
