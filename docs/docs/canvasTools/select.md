# Select tool

In the bottom left of the `Canvas` you will find a selection of tools. These are how you add annotation objects directly to the canvas.

![alt text](../static/img/select.png)

This tool is the default for interacting with the canvas. It allows you to select objects on the canvas and to pan around and zoom freely.

As explained in the Quickstart, `MIDDLE MOUSE` drag is the primary way to pan (along with `SPACE + LEFT`) and zooming is done by holding `CTRL` and using the mouse wheel. Trackpad interactions use standard gesture panning and pinch to zoom. 

### Selection

To select and individual element on the canvas, like a pulse, line or channel, simply `LEFT` click that object. To deselect, click on an empty region of the canvas. 

![alt text](../static/video/selectAndDeselect.gif)

In both trackpad and mice interactions, `LEFT` drag creates a selection marquee, allowing you to select multiple elements at once. When a multi-selection is present, you may drag the entire group of elements by hovering one of the selected elements and dragging like normal. 

![alt text](../static/video/multiSelect.gif)

You may also choose to group the elements at this stage. Multi-selections may also be made by selecting an object, then `CTRL` clicking objects you wish to add to the union.

In order to select sub-elements within groups, you must first select the group, then **double click** on the child element you wish to directly select. Grouped elements can then be removed from the group by selecting the "Ungroup" button.

![alt text](../static/video/groupChildSelectionDemo.gif)

:::tip

To selected small nested elements, zoom in so it is easier to double-click

:::
