# Banner

The banner contains lots of useful actions for interacting with your pulse sequence diagram.

- Open (`CTRL+O`): Open a diagram. This button opens the `Open Diagram` dialog, which is used for either opening a pulse sequence diagram from a file, one of the inbuilt sequences or one your 10 most recent worked-on diagrams.
- Export `.nmrd` (`CTRL+ALT+S`): Exports the worked-on diagram as a portable `.nmrd` file, for sharing and re-uploading.
- New (`CTRL+N`): Create a new diagram.
- Save As (`CTRL + SHIFT + S`): Create and save a new diagram from the currently opened diagram.
- Save (`CTRL + S`): Save the current diagram.
- Undo (`CTRL + Z`) 
- Redo (`CTRL + Y`)
- Export SVG (`CTRL + SHIFT + S`): Opens the SVG export dialog.
- Export PNG (`CTRL + E`): Opens the export PNG dialog.
